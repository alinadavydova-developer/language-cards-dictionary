Сервис хранит слова, их переводы, транскрипцию и озвучку без привязки к пользователю

## Настройка GRAFANA
Настройка Grafana и визуализация данных
Теперь, когда данные собираются в Prometheus, нужно их визуализировать в Grafana.

Вход в Grafana: Откройте браузер и перейдите по адресу http://localhost:3000. Введите логин и пароль admin/admin (система попросит сменить пароль при первом входе) .

Добавление источника данных (Data Source):

В левом меню зайдите в Connections -> Data sources.

Нажмите кнопку "Add data source".

Выберите Prometheus.

В поле URL введите http://prometheus:9090 (имя сервиса из docker-compose.yml) .

Нажмите "Save & Test". Вы должны увидеть сообщение об успехе.

Создание дашборда:

В левом меню выберите Dashboards -> + Create dashboard.

Нажмите "Add visualization".

В качестве источника данных выберите только что добавленный Prometheus.

В поле "Metric" введите название метрики, например, http_server_requests_seconds_count  или вашу кастомную custom_calls_total.

Grafana сразу покажет график. Вы можете менять стили, названия осей и добавлять новые панели.

Дополнительные рекомендации
Метрики для бизнеса: Не ограничивайтесь техническими метриками. С помощью кастомных метрик можно отслеживать количество заказов, зарегистрированных пользователей или любые другие бизнес-показатели .

Мониторинг БД и HTTP-клиентов: Micrometer умеет автоматически собирать метрики с популярных клиентов БД (Lettuce, HikariCP) и HTTP-клиентов (RestTemplate, WebClient), если они есть в вашем проекте .

Безопасность: Обязательно защитите endpoint /actuator/prometheus с помощью Spring Security, если ваше приложение смотрит в интернет. Вынесите его на другой порт (как мы сделали в примере) и/или ограничьте доступ по IP .
